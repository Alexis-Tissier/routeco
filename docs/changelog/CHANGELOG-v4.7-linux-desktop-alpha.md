# Détour 0.4.7 — première application Linux

- fenêtre desktop autonome basée sur Electron ;
- backend Python empaqueté avec PyInstaller ;
- runtime Java et GraphHopper 11 inclus ;
- téléchargement vérifié du pack France au premier lancement ;
- réutilisation locale des données aux lancements suivants ;
- production d'un AppImage et d'une archive tar.gz ;
